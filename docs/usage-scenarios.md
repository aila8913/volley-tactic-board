# 使用情境盤點

這份文件回答一個問題：**「誰、在什麼時機、身體處於什麼狀態下打開這個 app」**。

它存在的理由很具體：導覽與版面的爭論常常在原地打轉，因為每個人腦裡假設的情境不同，
而那個假設沒有被講出來。有了編號之後，討論可以變成「你說的是 B3 還是 A3？」——
這比反覆重述情境快得多。2026-08-11 的左欄導覽討論就是這樣收斂的（判準被推翻兩次，
兩次都是因為冒出一個沒被列進來的時機）。

**這份文件不放**：功能規格（去 `docs/product-spec.md`）、決策（去 `docs/adr/`）、
詞彙定義（去 `CONTEXT.md`）。使用者大類沿用 `docs/product-vision.md` 已定義的 TA，
不另立一套。

每個時機標三件事——**裝置**、**身體約束**、**時間預算**——因為介面該長什麼樣，
是被這三件事決定的，不是被功能決定的。

---

## 大類 A：數據夥伴（原型使用者）

自己就是分析者，技術耐受度高，願意花時間換完整資料。`product-vision.md` 裡
「曾經用 Excel 開慢速回放逐球記錄」的那個人。

| 編號   | 時機                        | 裝置       | 身體約束       | 時間預算 |
| ------ | --------------------------- | ---------- | -------------- | -------- |
| **A1** | 平時 · 賽前備課             | 電腦／平板 | 坐著，雙手可用 | 從容     |
| **A2** | 賽中 · 自己下場記簡易版     | 平板       | 眼睛不能離場   | 秒級     |
| **A3** | 賽後當晚 · 對著影片補進階版 | 電腦       | 坐著，雙手可用 | 1–2 小時 |
| **A4** | 賽後幾天 · 找洞察           | 電腦       | 坐著           | 從容     |
| **A5** | 平時 · 純粹想戰術           | 平板／電腦 | 坐著           | 從容     |

- **A1**：翻上一場的數據、翻以前存的戰術、排這場先發，可能同時開好幾個東西來回比對。
  這個時機**沒有「當前比賽」**——使用者是在整個帳號的歷史裡遊走。
- **A2**：系隊人手不足時，數據夥伴就是記錄者。行為等同 B2／B3，不另外計。
- **A3**：一場約 900 球逐球補填到位分與球線座標。需要影片能暫停倒帶（見 #21／#51）。
  唯一「單場沉浸」的時機——這裡反而**不希望**被導覽打斷。
- **A4**：跨場比對「誰的接發到位率在掉」、同一個人在兩支隊的差異。M4／#65 視圖②③的正主。
  同樣沒有「當前比賽」，聚合單位是人或球隊。
- **A5**：「下次遇到他們的快攻，接發要怎麼站」——腦裡有畫面，想開一塊板子畫下來，
  不對應任何一場已存在的比賽。**這個時機證明 `tactics.matchId` 綁死表達不了真實需求**：
  使用者根本還沒有那一場。

## 大類 B：球經（被指派要記錄的人）

關鍵洞察（`product-vision.md`）：**他們本來就得拿紙本記分表工作**。不一定對數據有興趣，
操作成本高於紙筆就不會換。

| 編號   | 時機                           | 裝置       | 身體約束       | 時間預算 |
| ------ | ------------------------------ | ---------- | -------------- | -------- |
| **B1** | 開賽前 5 分鐘 · 建比賽、排先發 | 平板       | 站著，可能單手 | 匆忙     |
| **B2** | 賽中 · 死球空檔記一分          | 平板       | 眼睛可短暫離場 | 5–10 秒  |
| **B3** | 賽中 · 一分還在進行            | 平板       | 眼睛不能離場   | ≈ 0      |
| **B4** | 賽中 · 換人／暫停／換局換輪    | 平板       | 突發、無預告   | 秒級     |
| **B5** | 賽中 · 發現剛剛記錯了          | 平板       | 壓力下         | 5–10 秒  |
| **B6** | 賽後 · 交差                    | 平板／手機 | 坐著           | 從容     |

- **B1**：站著、可能一邊喊人問背號、隊伍還在熱身，名單可能臨時少一個人。
  從「建立比賽」到「記第一分」的路徑必須極短，中間不能有需要思考的岔路。
- **B2／B3**：預算數字來自 `docs/recording-cost-budget.md`。這兩者的落差就是
  **簡易版與進階版之間是懸崖不是斜坡**的原因。B2 的意涵是：螢幕每一格空間都該留給記錄本身。
- **B4**：沒有預告，要在哨聲後幾秒內處理完，最容易漏記（見 #120）。得在計分頁當場處理，
  不能要求跳去別的頁面。
- **B5**：「上一分是 7 號扣的不是 12 號」。很真實但常被忽略的時機——紙本劃掉重寫很容易，
  app 不一定。撤銷／修改必須在計分頁本頁完成。
- **B6**：把結果給教練或群組。分享範圍依 `product-vision.md` 是「只匯圖」。
  **匯出是某個頁面的動作，不是一個目的地。**

## 大類 C：教練／隊長（只讀）

不記錄，只消費結果。可能連 app 都不是他打開的。

| 編號   | 時機                          | 裝置       | 身體約束  | 時間預算 |
| ------ | ----------------------------- | ---------- | --------- | -------- |
| **C1** | 賽中暫停 · 借過平板看一眼     | 別人的平板 | 會打斷 B2 | 30 秒    |
| **C2** | 賽後檢討 · 投影給全隊         | 大螢幕     | 一群人看  | 從容     |
| **C3** | 賽前 · 看對手球線分布決定佔位 | 平板       | 坐著      | 從容     |

- **C1**：想看現在誰狀況不好、輪到第幾輪。**這台平板正被球經拿著記分**——所以這個時機要求
  「翻走再翻回來，記到一半的分不能掉，而且要落回原本的位置」。**十七個時機裡只有這一個
  有這種要求**，其餘「隨時翻得開」的時機（A1／A5／C3）都是從容情境，普通導覽就夠。
- **C2**：球線分布圖的主場。對導覽沒有特別要求，但對「一頁講完一件事」有要求。
- **C3**：產品亮點的落地時機——翻出對手歷史 → 看熱區 → 開戰術板排佔位。
  **「數據」和「戰術板」在這裡是連著用的一對，而且用的是別場的資料。**

## 大類 D：球員本人（被動）

| 編號   | 時機                   | 裝置 | 身體約束   | 時間預算 |
| ------ | ---------------------- | ---- | ---------- | -------- |
| **D1** | 收到群組裡的一張匯出圖 | 手機 | 不是操作者 | —        |

`product-vision.md` 明寫「刻意不做：多人帳號、角色權限、球員登入看自己數據」，
所以球員永遠只是「收到一張圖的人」。**這條界線寫下來是為了之後有人提議個人主頁／通知／
球員自評時，能指著它問「那 D 就變成操作者了，這是要改定位嗎？」**

## 大類 E：場邊所有人（大記分板）

| 編號   | 時機                          | 裝置         | 身體約束     | 時間預算 |
| ------ | ----------------------------- | ------------ | ------------ | -------- |
| **E1** | 練習賽 · 只要一個看得到的比分 | 平板（架著） | 操作者不特定 | —        |
| **E2** | 幫別隊當裁判／記錄            | 平板         | 沒有我方名單 | 秒級     |

- **E1**：平板架在場邊，場上的人抬頭就看得到，按的人可能是任何一個路過的隊員。
  **唯一「使用者 ≠ 操作者」的時機，也是唯一不產生任何一球的時機。**
- **E2**：系隊之間互相幫忙輪值。你在記的是**別人的比賽**，它不該變成你帳號裡的一筆紀錄。
  **唯一「想記分，但沒有那一場」的時機**——而且不是「還沒決定」，是永遠不會有。

> E1／E2 產生的資料在 DB 裡會是「有比分、沒有一分一球」。schema 撐得住，但分析頁會看到
> 一場有比分沒內容的比賽——要排除在統計外、還是只貢獻勝負場次，是尚未回答的問題。

## 已知的空白

盤點的價值有一半在「列完之後發現沒被涵蓋的」。目前兩個：

1. **C1 完全沒有被設計過。** 它要求「30 秒內看懂現在誰不行」，而現有的分析頁都是為 A4
   （從容坐著找洞察）設計的。決定 C1 要看什麼，是「它該是浮層還是頁面」的前置問題——
   反過來會做出一個蓋住計分頁、但沒人看得完的東西。
2. **B5（記錯了要改）沒有出現在任何既有文件裡。** 球經在壓力下記錯是必然而非意外。

## 怎麼用這份文件

- 導覽／版面的爭論卡住時，先問「我們講的是哪個編號」。
- 提新功能時，指出它服務哪個編號；指不出來就是個訊號。
- 冒出沒被列進來的時機時，**補進這份文件**——2026-08-11 的判準被推翻兩次，
  兩次都是因為漏了一個時機（A5 與 E2）。
