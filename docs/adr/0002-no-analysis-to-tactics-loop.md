# ADR-0002：取消「分析 → 回跳戰術板改排陣」的閉環

- 狀態：Accepted
- 日期：2026-07-18（issue #76 於 2026-07-25 關閉）
- 來源：issue #76，實作分流至 #120、#65

## 背景

專案原本的立論是一個閉環：

> 賽前排陣 → 賽中記錄 → 賽後分析 → **一鍵跳回戰術板的第 N 輪修佔位** → 回到賽前排陣

最後那段回跳是整個閉環的關鍵動線，也是「球線分布圖」這個 wow 點原本預期兌現價值的地方。

但 ADR-0001 把戰術板定成**嚴格單向、用完即丟的白板、一份戰術 = 一景**。在那個模型下，「跳回戰術板某一輪去改排陣」沒有東西可以改 —— 白板不是排陣的真相來源，改了也不會回寫到任何地方。閉環的最後一段沒有著力點。

## 決定

**一、取消回跳閉環。**戰術板是隨手白板：賽前、賽中、賽後都能拉出來講解，講完收起，**不跟分析結果綁定回跳**。

**二、跨工具的連接點不靠一鍵回跳，改由計分流程主動問。**計分板按「下一局」時跳出「重新佈輪轉位」視窗，三個選項：

1. 照上次（沿用上一局佈陣）
2. 上一輪 / 下一輪（整組轉一格）
3. 重新排位（手動重佈）

這是局與局之間才問一次的**正式決策點**，取代原本隨時可回跳的動線。實作歸 #120：計分頁的常駐輪轉位是唯讀的「看」，換局視窗是唯一的「改」入口，寫的是逐局先發快照、不碰全域 store。

**三、閉環取消，但分析軸的三個問題保留**，續作為 #65 的上位依據：rally 的輪次 join key、分析頁以輪次還是球員為軸、賽前佔位疊球線分布（歸 M4）。

## 後果

- 分析頁不需要 deep link 回戰術板，也不需要「預選第 N 輪」的參數
- 「從數據改進排陣」變成使用者自己看完分析、下次比賽時在換局視窗做決定 —— 產品把判斷留給人，不做自動化建議
- 賽前佔位疊球線分布（M4）仍然做得到，靠的是 `rally.homeRotation` 欄位當鑰匙，不是靠回跳動線
- 代價：產品敘事少了一個閉環故事，「分析結果影響下一場」變成隱性的、靠使用者自己完成

## 不要重新提議

- 「分析頁加一顆按鈕跳回戰術板的第 N 輪」—— 沒有可寫回的目標，見 ADR-0001
- 「讓戰術板可以被分析頁帶參數開啟並套用站位」—— 同上，等於恢復雙向寫回
